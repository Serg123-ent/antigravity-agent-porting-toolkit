# Общие правила интеграции и разработки агентов в Antigravity

## Основные принципы
1. **Чистый Markdown**: Все инструкции агента пишутся на ясном и детерминированном Markdown без лишних оберток и XML-тегов, специфичных для других сред.
2. **Отсутствие фоновых шелл-хуков**: Любая логика валидации и проверки должна быть явно оформлена в виде шагов в правилах либо реализована через вызовы инструментов (tools/MCP).
3. **Безопасность и предсказуемость**: Всегда валидируйте команды и изменения перед их выполнением.
4. **Инструментальная модель**: Используйте стандартные инструменты среды (`view_file`, `write_to_file`, `replace_file_content`, `run_command`, `invoke_subagent`, `ask_question`).
